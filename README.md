# SQL Sales Analysis — Portfolio Project

## Project Overview
This project demonstrates practical MySQL skills by analyzing a fictional Nigerian retail sales dataset.

The analysis answers business questions around:
- Customer distribution
- Revenue performance
- Product and category performance
- Customer spending
- Monthly sales trends
- Revenue contribution by location

## Tools
- MySQL
- SQL
- CSV
- GitHub

**orders**

## Business Questions
1. What is total revenue?
2. What is the average order value?
3. Which city generates the most revenue?
4. Which product category performs best?
5. Who are the top customers by spending?
6. Which customers spend more than ₦300,000?
7. What is monthly revenue?
8. Which products sell the most?
9. Which customers have not placed an order?
10. Which orders are above the average order value?

## Key Portfolio Value
The project shows how raw transactional data can be transformed into business insights using SQL.

## How to Run
1. Create a MySQL database.
2. Run `schema.sql`.
3. Import the three CSV files.
4. Run `analysis.sql`.
5. Review the result sets and use them for charts/dashboard work.
